# Makewebbb UI runtime

The project uses React, Vite, React Router, Motion, a custom cursor, page transitions, theme support, and Gemini integration.

## Interaction rules
- Keep route transitions interruptible.
- Do not let the custom cursor become the only pointer feedback.
- Preserve readable text in both supported themes.
- Keep animation effects separate from core navigation.

## Responsive review
Check route changes, theme toggling, cursor behavior, and content spacing on touch devices as well as pointer devices.
