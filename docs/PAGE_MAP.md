# Makewebbb Page Map

The application uses React Router with five primary pages:

- / home
- /services services
- /work work
- /team team
- /contact contact

Shared navigation, footer, cursor, reveal, transition, and theme components sit above the page routes.

## Maintenance

When adding a new page, update the router and navigation in the same change. Test direct URL entry and refresh behavior so the route works independently of client-side navigation.
