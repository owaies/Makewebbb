# Makewebbb theme QA

Check theme behavior across a full reload and route change.

## Persistence
Select a theme, reload the page, and confirm the preference remains stable.

## Visual coverage
Check navigation, cards, text, buttons, forms, and footer in both themes.

## Browser integration
Verify browser-native controls and form surfaces remain legible after the theme changes.

## Accessibility
Keyboard focus must remain visible in both themes.
