# Makewebbb

A Vite + React interface project with Tailwind CSS, React Router, Motion, and an Express integration.

## Development

    npm install
    npm run dev

Production build:

    npm run build
    npm run preview

Type-check the project:

    npm run lint

## Notes

The project includes multiple UI theme states and browser-storage handling. Theme preference remains optional so the application can still render when browser storage is unavailable.
